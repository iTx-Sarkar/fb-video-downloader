# Facebook Video Downloader

This is a web application built with Node.js and Express that allows users to download Facebook videos by providing the video URL.

## Features
- Simple web interface to input Facebook video URLs.
- Server-side processing to extract video links.
- Clean and responsive UI.

## Project Structure
- `index.html`: The frontend interface for the user.
- `server.js`: Node.js backend using Express to handle requests.
- `package.json`: Project dependencies and metadata.

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   node server.js
   ```
4. Open your browser and go to `http://localhost:3000`.
